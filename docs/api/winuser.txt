@param lpMsg Message from GetMessageW or PeekMessageW.
@return Nonzero if the message was translated, 0 if not.

## TranslateMessage(lpMsg)
Posts character messages for virtual-key messages.

WM_KEYDOWN and WM_KEYUP produce WM_CHAR or WM_DEADCHAR, and the WM_SYS*
equivalents produce WM_SYSCHAR or WM_SYSDEADCHAR. Only works on messages
from GetMessageW or PeekMessageW. Windows CE has no scan codes or
extended key flag, so bits 16 to 24 of the generated WM_CHAR's lParam
aren't set.

@param lpMsg Message from GetMessageW or PeekMessageW.
@return TRUE if a character message was posted, FALSE otherwise.

## UnionRect(lprcDst, lprcSrc1, lprcSrc2)
Computes the smallest rectangle containing two rectangles.

Empty rectangles are ignored.

@param lprcDst Receives the union.
@param lprcSrc1 First rectangle.
@param lprcSrc2 Second rectangle.
@return TRUE if the union is not empty, FALSE if it is.

## UnregisterClassW(lpClassName, hInstance)
Removes a window class registered by the application.

Destroy every window of the class first. Classes are unregistered
automatically when the application exits. System classes can't be
removed.

@param lpClassName Class name, or an atom from RegisterClassW in the low
       word.
@param hInstance Module that registered the class.
@return TRUE on success, FALSE if the class wasn't found or still has
        windows (see GetLastError).

## UnregisterHotKey(hWnd, id)
Frees a hot key registered by the calling thread.

@param hWnd Window passed to RegisterHotKey.
@param id Identifier passed to RegisterHotKey.
@return TRUE on success, FALSE on failure (see GetLastError).

## UpdateWindow(hWnd)
Repaints a window immediately if it has an update region.

Sends WM_PAINT straight to the window procedure, bypassing the queue.
Does nothing if the update region is empty.

@param hWnd Window to update.
@return TRUE on success, FALSE on failure.

## ValidateRect(hWnd, lpRect)
Removes a rectangle from a window's update region.

WM_PAINT keeps arriving until the update region is validated. BeginPaint
validates the whole client area.

@param hWnd The window. Windows CE doesn't accept NULL.
@param lpRect Rectangle to validate, in client coordinates.
@return TRUE on success, FALSE on failure.

## WindowFromPoint(Point)
Returns the window at a point on the screen.

Hidden and disabled windows are skipped; ChildWindowFromPoint doesn't
skip them.

@param Point The point, in screen coordinates.
@return The window, or NULL if there is none at the point.

## wsprintfW(lpOut, lpFmt)
Formats values into a string buffer, printf style.

Supports %[-][#][0][width][.precision]type with types c, d, i, u, x, X,
s and S, but not floating point: %f prints f and misreads the values
after it. Output stops at 1023 characters plus the terminating null, and
the return value is then 1024. There's no other buffer size check, so
make lpOut large enough. Only the Unicode version exists on Windows CE.

@param lpOut Buffer that receives the output.
@param lpFmt Format string, followed by the values to format.
@return Characters written, not counting the terminating null, or a
        value less than the format string's length on failure.

## wvsprintfW(lpOut, lpFmt, arglist)
Formats values from a va_list into a string buffer, printf style.

Same formats and 1023-character limit as wsprintfW. There's no other
buffer size check. Only the Unicode version exists on Windows CE.

@param lpOut Buffer that receives the output.
@param lpFmt Format string.
@param arglist Values to format, from va_start.
@return Characters written, not counting the terminating null, or a
        value less than the format string's length on failure.
